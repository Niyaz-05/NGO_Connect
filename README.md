# NGO Connect

A web platform that connects NGOs with volunteers and donors. NGOs publish volunteer opportunities and
report how funds are used, volunteers find and apply for work, donors contribute and follow the results,
and administrators verify NGOs and oversee the platform.

## Stack

| Layer | Technology |
|---|---|
| Back end | Java 17, Spring Boot 2.7, Spring Web, Spring Data JPA, Spring Security with JWT (jjwt), Spring Mail, ModelMapper |
| Database | MySQL (schema generated by Hibernate, `ddl-auto=update`) |
| Front end | React (Create React App), React Router, React-Bootstrap, axios, react-toastify |

## Repository layout

```
ngo-connect-backend/   Spring Boot API
ngo-connect-react/     React front end
```

## Roles and access control

There are four user types — `DONOR`, `VOLUNTEER`, `NGO` and `ADMIN`. The API is stateless: clients
authenticate through `/api/auth/**` and send the returned JWT as a bearer token. The administrator
endpoints (NGO approval and rejection, donation oversight, platform statistics and alerts) are protected with
method-level `@PreAuthorize("hasRole('ADMIN')")` rules.

## What is implemented

- **NGOs:** registration, verification requests, admin approve/reject, volunteer opportunities with
  urgency levels, fund reports and fund-utilization reports.
- **Volunteers:** browse opportunities and submit applications, tracked through application statuses.
- **Donors:** make donations (payment method and status are recorded); fund reports are readable without
  logging in through the public `/api/transparency/reports` endpoints.
- **Admins:** NGO management, approval of volunteer opportunities, donation oversight (including reports
  by NGO and by cause, and a suspicious-pattern check), a dashboard, platform statistics and system alerts.

## Run it locally

**Prerequisites:** JDK 17, Maven, Node 18+, MySQL.

1. Create the database:
   ```sql
   CREATE DATABASE ngoconnect;
   ```
2. Configure the API. Copy `ngo-connect-backend/.env.example` to `ngo-connect-backend/.env` and fill it in
   (the file is git-ignored; `spring-dotenv` loads it when you run the API from that directory). The API
   will not start without `DB_PASSWORD` and `JWT_SECRET`, because no secrets are stored in the repository.
   `JWT_SECRET` must be at least 32 characters, for example `openssl rand -hex 32`.
3. Start the API on port 8080:
   ```bash
   cd ngo-connect-backend
   mvn spring-boot:run
   ```
4. Start the front end:
   ```bash
   cd ngo-connect-react
   npm install
   npm start
   ```
   Several components call the API at `http://localhost:8080` directly, so the API needs to be running there.

Email sending is optional: verification is disabled by default (`app.email.verification.required=false`).
Set `MAIL_USERNAME` and `MAIL_PASSWORD` (an app-specific password) only if you enable it.

## Known issues

- `ngo-connect-react/ngo-connect-react/` is a second copy of the React app that differs from its parent in
  a few source files; it is kept for now and should be reconciled or removed.
- The front end hard-codes the API base URL in several components instead of using a single configuration value.
- `POST /api/admin/fix-ngo-status` is a one-off data-repair endpoint that is currently reachable without
  authentication; it should be removed or restricted before any real deployment.
- Test coverage is minimal: there is one unit test (`DonationServiceTest`).
